# Source Document Context — Smart Hospital Management System (SHMS)

This directory references the primary source requirement document:

`Smart_Hospital_Management_System.pdf`

## Key Metadata Extracted from Source:
- **System Name**: Smart Hospital Management System (SHMS)
- **Primary Objective**: Integrated automation of inpatient, outpatient, diagnostic, clinical, administrative, and financial hospital operations.
- **Core Modules**:
  1. Patient Registration
  2. Appointment & OP Management
  3. Inpatient (IP) Management
  4. Laboratory Management
  5. Pharmacy & Inventory
  6. Billing & Payment
  7. Reports & Analytics
  8. Security & Administration
- **Actors**: Patient, Receptionist, Doctor, Lab Technician, Pharmacist, Cashier, Admin.
- **Core Workflow**: Registration -> Appointment -> OP Check-in -> Doctor Consultation -> (Lab Test / Admission decision forks) -> Prescription & Dispensing -> Billing & Payment -> Discharge & Follow-up.
