# Experiment 1: OOAD Fundamentals & UML Tool Familiarization

## Lab Record Header
- **Experiment Number**: 01
- **Title**: Object-Oriented Analysis and Design (OOAD) Fundamentals and UML Tooling Familiarization
- **Date**: Academic Session 2026

---

## 1. Aim
To study and understand the fundamental concepts of Object-Oriented Analysis and Design (OOAD), Software Development Life Cycle (SDLC) phases, Unified Modeling Language (UML) diagram classification, and gain hands-on familiarization with UML modeling tooling using Mermaid.js text-based representations.

---

## 2. Objectives
1. Understand the 7 core phases of SDLC and map them to the Smart Hospital Management System (SHMS).
2. Explore foundational OOAD principles: Object, Class, Encapsulation, Abstraction, Inheritance, Polymorphism, Association, Aggregation, Composition, Generalization, and Dependency.
3. Classify UML 2.5 diagrams into Structural, Behavioral, and Interaction categories.
4. Learn model creation, diagram generation, and export procedures in modern UML tools (StarUML and Mermaid.js).
5. Construct introductory basic and relationship-focused class diagrams for SHMS.

---

## 3. Documents & Diagrams Created
1. `ooad-fundamentals.md` — In-depth academic explanation of SDLC & OOAD principles with SHMS domain examples.
2. `uml-tool-familiarization.md` — Guide to StarUML and Mermaid syntax workflow.
3. `basic-class-diagram.mmd` — Basic class model showing core SHMS classes and methods.
4. `relationships-class-diagram.mmd` — Advanced class model highlighting Association, Aggregation, Composition, Inheritance, and Dependency.

---

## 4. Procedure
1. Conducted domain study of SHMS core entities (`Person`, `Patient`, `Doctor`, `Hospital`, `Department`, `Appointment`, `MedicalRecord`).
2. Mapped real-world hospital interactions to object-oriented abstraction layers.
3. Authored formal markdown documentation defining SDLC phases and OOAD tenets.
4. Formulated Mermaid class diagram scripts specifying attributes, operations, and relationships.
5. Parsed and validated diagram syntax against UML 2.5 structural specifications.

---

## 5. Result
The OOAD principles and UML tool workflows were successfully analyzed and applied. Introductory class diagrams for the Smart Hospital Management System were authored in Mermaid format and validated.

---

## 6. Conclusion
Experiment 1 establishes the theoretical foundation and tool proficiency required to analyze, model, and document complex software systems like SHMS using standardized UML representations.
